# JoPoJo 長遠目標同擴展路線

最後更新：2026-08-23

## 1. 最終目標

JoPoJo 想成為一間基地喺香港嘅公司，核心業務係圍繞場地展銷、細小攤檔、pop-up、短期空間使用，幫助資本有限但想創業或試業嘅人，以更低風險接觸真實顧客。

平台同時幫場地持有方同發展商，除咗傳統長租商舖外，用短期攤位、活動、展銷、pop-up 去提升人流、氣氛同空間使用率。

長遠希望由香港出發，擴展到大灣區、東南亞，甚至其他國際市場。

## 2. 核心宗旨

誠信先行。

平台唔可以靠誇大回報、隱瞞風險、亂做認證或鼓勵灰色交易增長。所有功能、內容、收費、合作都要建立透明同信任，先可以令場地方、小商戶、發展商同用戶長期使用。

## 3. 三個發展階段

### Stage 1：情報營運服務

目標：證明平台可以穩定收集、整理、發布場地資訊，並帶來真實查詢。

主要用戶：

- Mercy
- 相熟場地搞手、代理人、場主
- 想搵短租 booth、市集檔、展銷位嘅小商戶

主要功能：

- Telegram intake
- AI 整理 listing
- Mercy 審核
- 公開場地列表
- IG / Facebook 內容草稿
- WhatsApp 直接聯絡

進入下一階段門檻：

- 30-50 個已批准 listing；
- 穩定每週新供應；
- 有重複回訪用戶；
- 有實際 WhatsApp 查詢；
- 有場地方願意為曝光或查詢付費。

### Stage 2：網絡平台

目標：由情報服務變成雙邊平台，令租客同場地方主動使用。

新增功能：

- 用戶儲存搜尋條件同 alert
- 場地提交同更新表單
- 表現數據：瀏覽、查詢、收藏、聯絡
- 簡單評價同回報系統
- 收費曝光、精選欄位、週報贊助
- 場地方月費方案
- 更多內容分類：市集、商場、街市、工廈、地舖、私人場地

可以開始接觸：

- 中大型場地營運方
- 商場推廣部
- 活動策劃公司
- 穩定放場嘅代理或二房東

但唔應該太早將銷售重心放喺領展等大發展商，因為銷售週期長、合約同採購要求高，唔適合一間一人公司早期投入大量精力。

### Stage 3：實體零售空間生態

目標：成為亞太區實體零售空間流動基礎設施。

可能方向：

- 連接商場發展商同小品牌做短期 pop-up
- 為小商戶提供開檔工具：清單、預算、保險、拍攝、設計、物流
- 連接批發商或供應商，幫小商戶搵貨
- 為場地方提供人流、檔期、銷售表現分析
- 跨境擴展到大灣區、新加坡、吉隆坡、曼谷等市場
- API 或數據服務俾場地集團同活動公司

呢個階段先認真考慮：

- 企業合作
- 發展商合約
- 批發／供應鏈合作
- 城市擴展
- 團隊招聘

## 4. 唔可以太早做嘅事

以下方向有潛力，但喺 Stage 1 唔應該投入主要資源：

- 主動銷售俾領展或大型發展商
- 批發商配對
- 供應鏈服務
- 跨境法律和合規
- 複雜 SaaS dashboard
- 金流、合約、糾紛處理
- Verified Badge 收費認證
- 全自動社交發布

原因：呢啲功能會大幅增加成本、責任同營運複雜度，但未證明核心需求前回報太低。

## 5. 商業原則

- 先幫用戶慳時間，再諗收費。
- 先做資訊透明，再做信任工具。
- 先有穩定供應，再做平台網絡。
- 先有查詢價值，再向場地方收費。
- 唔碰錢、唔碰合約、唔做擔保，直到法律同營運能力足以承擔。
- 所有擴展都要用真實數據推動，唔好靠幻想。
